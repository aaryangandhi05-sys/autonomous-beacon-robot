# Autonomous Beacon Navigation Robot

An autonomous robot programmed in C to navigate an arena and respond
to red and green light beacons.

## Project Objective

The robot was required to complete five tasks:

1. Navigate to the red beacon
2. Turn off the red beacon
3. Navigate to the green beacon
4. Pick up the green beacon
5. Exit the arena

Our team completed all five tasks.

## My Contributions

- Developed and tested robot navigation logic in C
- Used light sensor readings to distinguish between red and green beacons
- Adjusted movement behavior based on sensor input
- Tested and refined the control logic
- Replaced and recalibrated a failed sensor on the day of the final demonstration
